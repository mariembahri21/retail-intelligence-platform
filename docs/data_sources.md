
# Data Sources

## M5 Forecasting dataset

The M5 Forecasting - Accuracy dataset contains historical daily sales of Walmart products across stores in California, Texas, and Wisconsin. The competition was hosted on Kaggle by the University of Nicosia, and Addison Howard, inversion, Spyros Makridakis, and Vangelis Spiliotis are credited in the official competition citation.

**Source:** [M5 Forecasting - Accuracy on Kaggle](https://www.kaggle.com/competitions/m5-forecasting-accuracy)

**Download date:** 2026-10-12

## Files used

- `sales_train_evaluation.csv`: Daily unit sales for each item and store, covering 1,941 days (`d_1` to `d_1941`).
- `calendar.csv`: Calendar dates, weekdays, special events, and SNAP programme indicators.
- `sell_prices.csv`: Weekly selling prices for individual items at each store.

The file `sales_train_validation.csv` is not used because it contains a shorter version of the same historical sales data, covering days `d_1` to `d_1913`. The file `sample_submission.csv` is also excluded because it is intended for preparing competition submissions and is not required for this project's analytics pipeline or inventory simulation.

## Terms of use

The official [Kaggle competition rules](https://www.kaggle.com/competitions/m5-forecasting-accuracy/rules) restrict the use of competition data outside the competition to non-commercial purposes only. This project is a non-commercial portfolio project intended for educational purposes and to demonstrate data engineering, demand forecasting, and inventory analytics.

This documentation does not attempt to interpret anything beyond what is stated on the official rules page. Anyone using the dataset is responsible for reviewing and complying with the applicable terms.

## Redistribution

The raw M5 data files are not included in this repository. They are excluded through `.gitignore` to prevent the original competition data from being committed to or redistributed through the repository.

Anyone wishing to reproduce this project must review and accept the applicable Kaggle competition rules and download the required files directly from the [official Kaggle data page](https://www.kaggle.com/competitions/m5-forecasting-accuracy/data).

## Simulated data

Inventory levels, stock movements, supplier information, lead times, purchase orders, and replenishment events do not come from the M5 dataset; they will be generated by the retail operations simulator developed for this project. The simulation logic, assumptions, business rules, and generated data structures will be documented separately.
